Provenance Tool v0.1

Generate a basic publication record containing declared authorship, version, release date, citation, canonical source, and related-file information. 在作品公开发布前，生成包含作者、版本、发布日期、引用方式、 规范来源和相关文件信息的基础记录。

Before You Begin · 使用说明

Complete the form, review the information, and generate the record. Download or copy the result and keep it with the corresponding work. 填写并核对作品信息后生成记录，再将结果下载或复制， 与对应作品一起保存或发布。

Information entered here is processed in your browser and is not automatically stored by this website. 您填写的内容仅在当前浏览器中处理，本网站不会自动保存这些信息。

Select the type that best describes the work. 选择最符合本次作品的类型。

Enter the official title used for this release. 填写本次发布所使用的正式标题。

Enter the author, creator, organization, or responsible maintainer. 填写作者、创作者、机构或负责维护该作品的主体。

Enter the version of the work, not the version of this tool. 填写作品本身的版本，不是本工具的版本。

Enter the date this version is officially released or made public. 填写这一版本正式发布或公开的日期。

Enter the permanent public URL where this specific work is officially published, maintained, or expected to be cited. 填写该具体作品正式发布、长期维护或应被引用的永久公开网址。

Enter a short factual description of the work. 填写对作品内容和用途的简短、客观说明。

Enter one filename per line. 每行填写一个文件名，没有相关文件时可以留空。

生成后，引用文本将显示在这里。

Public Boundary · 公开边界

This tool supports documentation and traceability. It does not prove originality, determine legal ownership, verify truth, resolve authorship disputes, create copyright registration, or replace human judgment. 该工具用于支持记录与可追踪性，但不能证明原创性、判断法律所有权、 验证真实性、解决作者争议、完成版权登记或代替人类判断。
