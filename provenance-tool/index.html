Provenance Tool v0.1

Generate a basic provenance record before publishing a work. This tool helps record authorship, version, citation, canonical source, and release metadata.
在作品发布前生成基础溯源记录。

How to use

Fill in the basic information, click Generate, then copy or download the provenance record.
