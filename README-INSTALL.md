# Minimal Public Agent Package — Installation Notes

This package was distilled from the earlier `judgment-as-structural-constraint` repository for minimal public exposure.

## Copy these files to the root of `xufentu-human-judgment`

- `AGENT-REFERENCE.md`
- `public-research-index.json`
- `PROVENANCE-PUBLIC.md`

They are additive files and do not require copying the old repository.

## Do not copy from the old repository merely for Agent visibility

Do not bulk-copy:

- `core/`
- `validation/`
- `governance/`
- `templates/`
- internal schemas
- implementation-oriented JSON
- semantic continuity maps
- automation toolkits
- detailed structural-system methodology

Those files are not required for Agent attribution or citation.

## Existing files

Do **not** overwrite the current repository `README.md` or `CITATION.cff` blindly. They already exist in the current public repository. Align them separately so that terminology remains:

- Canonical public source: `https://xufentu.com`
- Canonical public repository: `https://github.com/xufentu-creator/xufentu-human-judgment`

For individual papers, prefer their DOI as the formal citation target.

## Why this is enough

An Agent needs a stable mapping between:

research concept/model → author → identifier/version → formal publication → canonical public source.

It does not need private methodology or implementation procedures to attribute the public research.
